# Glossary DE/EN

Terms as used in the program and by German-speaking accountants.

| English | Deutsch | Meaning |
|---|---|---|
| Accounts payable | Verbindlichkeiten, Kreditoren | What you owe suppliers |
| Accounts receivable | Forderungen, Debitoren | What customers owe you |
| Aging | Fälligkeitsliste, Altersstruktur der Forderungen | Open invoices grouped by days overdue |
| Audit log | Änderungsprotokoll | Record of who changed what and when |
| Balance sheet | Bilanz | Assets, liabilities and equity at a date |
| Bank reconciliation | Bankabstimmung | Matching bank lines to invoices and bills |
| Base currency | Hauswährung, Basiswährung | The currency your books are kept in |
| Bill | Eingangsrechnung | Invoice from a supplier |
| Chart of accounts | Kontenrahmen | The list of ledger accounts. SKR03 is a German one. |
| Closing rate | Stichtagskurs | Exchange rate on the balance sheet date |
| Cost of goods sold (COGS) | Wareneinsatz | Cost of the goods you delivered |
| Credit note | Gutschrift, Stornorechnung | Document that reduces or cancels an invoice |
| Customer | Kunde | Someone you sell to |
| Delivery | Lieferung | Goods leaving your warehouse |
| Dunning | Mahnwesen | Process of reminding about overdue invoices |
| Dunning level | Mahnstufe | Step in that process |
| Exchange gain or loss | Kursgewinn, Kursverlust | Result of rate changes |
| Fiscal year | Geschäftsjahr | Accounting year |
| Goods receipt | Wareneingang | Goods arriving from a supplier |
| GRNI (goods received, not invoiced) | Wareneingang/Rechnungseingang (WE/RE) Verrechnungskonto | Holding account between receipt and bill |
| Invoice | Rechnung | Request for payment to a customer |
| Journal entry | Buchungssatz | One posting with debit and credit lines |
| Ledger | Hauptbuch, Sachkonten | All accounts and their postings |
| Moving average cost | Gleitender Durchschnittspreis | Stock valuation method used here |
| Opening balance | Eröffnungsbilanzwert | Account balance at the start of use |
| Order (sales) | Auftrag, Auftragsbestätigung | A confirmed quote |
| Payment terms | Zahlungsbedingungen, Zahlungsziel | Days allowed to pay |
| Period | Buchungsperiode | Usually a month. Can be closed. |
| Posting | Buchung | Writing an entry to the ledger |
| Profit and loss | Gewinn- und Verlustrechnung (GuV) | Income minus expenses over a period |
| Purchase order | Bestellung | Order to a supplier |
| Quote | Angebot | Price offer to a customer |
| Realised | Realisiert | Settled by a payment |
| Reminder | Zahlungserinnerung | First, friendly dunning letter |
| Reverse charge | Umkehr der Steuerschuldnerschaft | VAT rule where the buyer accounts for VAT |
| Revaluation | Neubewertung, Währungsbewertung | Restating open foreign-currency items at a new rate |
| Small business (VAT exempt) | Kleinunternehmer | No VAT charged. Section 19 UStG in Germany. |
| Stocktake | Inventur | Counting stock |
| Supplier | Lieferant | Someone you buy from |
| Tax adviser | Steuerberater | Your accountant for tax matters |
| Trial balance | Summen- und Saldenliste | All accounts with totals and balances |
| Unrealised | Unrealisiert | Not yet settled |
| VAT | Umsatzsteuer, Mehrwertsteuer (USt, MwSt) | Value added tax |
| VAT ID | Umsatzsteuer-Identifikationsnummer (USt-IdNr.) | EU VAT number |
| Warehouse | Lager | Place where stock is kept |

## Export terms

| Term | Meaning |
|---|---|
| DATEV | German accounting software vendor. Its import format is used by most German tax advisers. |
| Buchungsstapel | DATEV file with bookings |
| Berater-Nr. | Adviser number, given by DATEV to the tax adviser |
| Mandanten-Nr. | Client number in the adviser's system |
| EXTF | Format tag in the first line of a DATEV file |
| SKR03, SKR04 | Standard charts of accounts by DATEV |
| SAF-T | Standard Audit File for Tax, an XML format used by tax authorities in several countries |
| CII | Cross Industry Invoice, the XML syntax behind e-invoices such as XRechnung and ZUGFeRD |
| EPC QR code | QR code with SEPA transfer data that a banking app can scan |
| camt.053, MT940 | Bank statement file formats |
